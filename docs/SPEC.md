# プロジェクト仕様書：日本の偉人 名言サイト

あなたはこの仕様書に従い、静的サイトを新規構築してください。
本ドキュメントは「仕様」「文言ガイド」「実装手順」をすべて含みます。
不明点は自明な範囲で判断し、判断した内容は README に記録すること。

---

## 0. サイト名候補（実装時に1つ選び、README に記載）

1. ことのは年代記（Kotonoha Chronicle）
2. 日本の言葉、日本の心
3. 名言の年表
4. 継ぐ言葉（Tsugu Kotoba）

推奨：1（和名＋英名の併記が映える）

---

## 1. コンセプト

日本の歴史上の人物（古代〜現代の経営者まで）の
**「名言」「人物史の要約」「肖像・イラスト」** を年代別にまとめ、
そこから **日本文化の良さが自然に立ち上がってくる** サイト。

- 学習にも読み物にも使える。1ページ2〜3分で読み切れる分量。
- 押しつけがましい礼賛はしない。**事実と言葉に語らせる**。
- 一次情報は日本語版 Wikipedia を基本とし、**必ず自分の言葉に要約**する。

## 2. 技術スタック

- **Astro 5**（静的生成）+ TypeScript
- **Tailwind CSS v4**
- コンテンツ：`src/content/people/*.json`（Astro Content Collections + Zod スキーマ）
- 検索：**Pagefind**（ビルド時インデックス、JS依存を最小化）
- デプロイ想定：Cloudflare Pages（`npm run build` → `dist/`）
- 画像：`astro:assets` で最適化。外部URL直リンクは禁止（§9 の権利ルール参照）
- Node 20+ / npm

理由：全ページ静的、表示が速い、コンテンツが JSON で管理しやすい。
（別スタックを選ぶ場合は理由を README に書くこと）

## 3. データモデル

`src/content.config.ts` に Zod スキーマを定義する。

```ts
person: {
  id: string;            // slug（ローマ字, 例 "shibusawa-eiichi"）
  name: string;          // 渋沢栄一
  kana: string;          // しぶさわ えいいち
  nameEn: string;        // Eiichi Shibusawa
  eraId: string;         // 年代ID（§4）
  birth: number | null;  // 西暦（不明は null）
  death: number | null;
  fields: string[];      // ["実業家","官僚"]
  headline: string;      // 30字以内のキャッチ「日本資本主義の父」
  summaryShort: string;  // 60〜80字。一覧カード用
  history: string;       // 400〜600字。3段落。Wikipediaの要約（丸写し禁止）
  quotes: {
    text: string;        // 名言本体
    reading?: string;    // 古語・漢文の場合の読み下し／現代語
    meaning: string;     // 80〜120字の解説（§8.5 のテンプレに従う）
    source: string;      // 出典（書名・章など。不明なら「伝承」と明記）
    confidence: "確実" | "諸説あり" | "伝承";
  }[];
  values: string[];      // 「日本の良さ」タグ（§6 の8軸から1〜3個）
  image: {
    src: string;         // ローカル配置パス
    credit: string;      // 作者／所蔵
    license: string;     // "Public Domain" 等
    sourceUrl: string;
  } | null;
  related: string[];     // 関連人物 id
  refs: { title: string; url: string; license: string }[];
}
```

**重要**：画像が用意できない人物は `image: null` とし、
`values` の色を使った**抽象パターンのプレースホルダー**を自動生成すること
（家紋風・波紋風の SVG を CSS/SVG で生成。実在の紋章の無断使用は避ける）。

## 7. ページ構成

```
/                        トップ（年表 + 今日の一言 + 8軸入口）
/eras/[eraId]            年代別一覧
/people/[id]             人物ページ（メイン）
/values/[valueId]        価値観別一覧
/quotes                  名言一覧（フィルタ・検索）
/about                   このサイトについて・出典・ライセンス
```

### 7.1 トップ

1. ヒーロー：サイト名 + リード文（§8.3）
2. **横スクロール年表**：飛鳥→現代。年代ブロックに代表3名の顔を並べる
3. 「今日の一言」：日付をシードに決定的に1つ選ぶ（毎日変わるがビルド後も安定）
4. 8軸カード
5. 経営者セクション

### 7.2 人物ページ（最重要）

```
[肖像画像]  名前（かな） / 生没年 / 分野タグ
headline（大きく）
──────────
■ 言葉
  quote 1（大きな縦組み風タイポ）
    └ 現代語 / 意味の解説 / 出典・確度バッジ
  quote 2, 3...
──────────
■ この人の歩み（history 400〜600字, 3段落）
──────────
■ この言葉が映すもの（values タグ + 1文の説明）
──────────
■ 同じ時代の人 / 近い言葉の人（related）
──────────
■ 出典（refs へのリンク + ライセンス表記）
```

- 名言は**縦書き（`writing-mode: vertical-rl`）**を大画面で採用、
  モバイルは横書きにフォールバック。
- フォント：明朝系（`Noto Serif JP`）を本文と名言に、
  UI ラベルはゴシック（`Noto Sans JP`）。可変フォントを subset して読み込む。

## 8. 文言ガイド（トーン＆マナー）

### 8.1 基本方針

- **主語を大きくしない**。「日本人は〜だ」ではなく「この人はこうした」。
- 他国との比較で優劣をつけない。**日本の良さは、事実の積み重ねで見せる**。
- 歴史評価が分かれる人物は、断定を避け「〜と評される」「諸説ある」と書く。
- 敬体（です・ます）で統一。読者は中学生以上を想定。

### 8.2 NG例 → OK例

- ✕「日本人だけが持つ精神性」 → ○「この時代の日本で育まれた考え方」
- ✕「世界一の技術」 → ○「当時の世界水準に並んだ技術」
- ✕「偉大な英雄」 → ○「後世に大きな影響を残した人物」

### 8.3 トップのリード文（そのまま使用可）

```
千年をこえて、まだ残っている言葉があります。
戦国の武将も、江戸の職人も、明治の学者も、昭和の経営者も、
それぞれの時代の困難のなかで、たった一行を残しました。
その一行と、その人が歩いた道を並べてみると、
この国が何を大切にしてきたのかが、少しだけ見えてきます。
```

### 8.4 年代リード文サンプル

- **戦国**：「明日をも知れない時代に、人はどう決断したのか。乱世の言葉には、迷いを断つための強さと、意外なほどの繊細さが同居しています。」
- **明治**：「学び、迷い、それでも前へ。外の世界と出会った日本が、何を取り入れ、何を守ろうとしたのか。その葛藤が、そのまま言葉になっています。」
- **経営者**：「ものをつくり、人を育て、会社を続ける。その現場から生まれた言葉は、飾りがないぶん、いまも直接届きます。」

### 8.5 名言解説テンプレ（meaning フィールド）

必ず3要素・80〜120字：

```
【状況】いつ・どんな場面で言われたか（または語られてきたか）
【意味】言葉が指していること（現代語で平易に）
【今日へ】現代の読者にとっての受け取り方を1文（説教しない）
```

例（吉田松陰）：

> 松下村塾で門下生に語ったとされる言葉です。志とは、才能ではなく「本気で
> やり通す覚悟」のことだと説いています。うまくできるかどうかより、まず
> 続ける側に立つ。そう読み替えると、いまの学びにも重なります。

### 8.6 history の書き方（3段落）

1. 生まれと転機（何がこの人を動かしたか）
2. 中心となる仕事（何を成したか。数字や具体名を入れる）
3. 残したもの（後世への影響。過度な賛辞は避ける）

## 9. 権利・出典ルール（厳守）

1. **Wikipedia の文章をそのままコピーしない。** 必ず要約・再構成する。
   参照した場合は `refs` に記事URLと `CC BY-SA 4.0` を明記し、
   `/about` にライセンス説明ページを置く。
2. **画像**は以下のみ使用可：
   - パブリックドメイン（作者没後70年超、または明確に PD 表示のもの）
   - Wikimedia Commons で PD / CC0 / CC BY と明示されたもの
   - → **ローカルに保存**して `src/assets/portraits/` に配置。ホットリンク禁止。
   - 各画像に credit / license / sourceUrl を必ず記録し、人物ページに小さく表示。
3. **存命または近年物故の人物（特に昭和以降の経営者）**：
   - 肖像画像は原則使わない（肖像権配慮）。`image: null` でプレースホルダー。
   - 名言は**短い引用**にとどめ、`source` に書名・発言の出典を必ず記す。
   - 出典が確認できない言葉は `confidence: "伝承"` とするか、収録しない。
4. 出典不明の「ネットで有名な名言」は採用しない。確認できないものは落とす。

## 10. 実装フェーズ

**Phase 1：基盤**

- Astro プロジェクト初期化、Tailwind、Content Collections スキーマ、
  年代・価値観の定義ファイル、ルーティングの骨組み、
  サンプル人物3名（織田信長 / 渋沢栄一 / 千利休）で全ページを通す。

**Phase 2：コンテンツ**

- §5 Phase 1 の30名分の JSON を作成。文言ガイドに従って執筆。
- 画像はライセンス条件を満たすもののみ収集。無理なら `null`。

**Phase 3：仕上げ**

- 横スクロール年表、Pagefind 検索、OGP 画像自動生成、
  JSON-LD（Person schema）、ダークモード、
  a11y チェック（コントラスト比 4.5:1 以上、キーボード操作、alt）。

**Phase 4：README**

- 人物の追加手順、文言ガイドの要点、ライセンス方針を記載。
